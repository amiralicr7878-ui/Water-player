# Water Player

Standalone Android music player built around the supplied Liquid Neon HTML interface. The original visual layer and CSS animations are retained; Android-native integration adds MediaStore library discovery and a MediaSession-backed playback notification for Samsung Now Bar / lock-screen controls.

## Build
GitHub Actions builds a debug APK on every push to `main`. Open **Actions → Build Water Player APK** and download the `Water-Player-APK` artifact.

## Application ID
`com.amiralicr.waterplayer.debug` (debug build), separate from previous player apps.
